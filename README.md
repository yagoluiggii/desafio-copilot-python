# Resolvendo Códigos em Python com o GitHub Copilot

## 📝 Descrição do Projeto
Este projeto foi desenvolvido como parte de um desafio prático com o objetivo de explorar o uso do **GitHub Copilot** como assistente de IA no desenvolvimento e otimização de algoritmos em Python.

## 🎯 Objetivos
- Utilizar o GitHub Copilot para acelerar a escrita de código.
- Implementar e otimizar algoritmos em Python.
- Documentar as decisões técnicas e padrões adotados durante o desenvolvimento.

## 🛠️ Funcionalidades Desenvolvidas
1. **Concatenação de Dados:** Recebe duas entradas do utilizador e combina-as numa única saída.
2. **Repetição de Textos:** Solicita uma string e um número inteiro para retornar a string repetida.
3. **Operações Matemáticas Simples:** Realiza cálculos básicos entre dois números inseridos.
